# ArtifactsMarketing

The complete 26-week go-to-market plan for **ParentProof** in Delhi NCR
(28 Jul 2026 → 25 Jan 2027), targeting ₹1 crore gross revenue.

## Download

Clone the repo, or download files individually from the GitHub UI
(open the file → **Download raw file**).

## The five files

| # | File | What it is |
|---|---|---|
| 01 | `01_MASTER_PLAN.md` | **Read this first.** Positioning, ICP, channel strategy, the ₹1 Cr math, guardrails, risk register, and an honest reality check on the target. |
| 02 | `02_DayByDay_26Week_Plan.xlsx` | **The daily driver.** 182 authored days — tasks, channel, KPI target, estimated spend, and a blank column for your actuals. Filter to today's date each morning. |
| 03 | `03_Revenue_Funnel_Budget_Model.xlsx` | Live model. Edit the blue cells and every downstream number recalculates. Tabs: Assumptions · Weekly Model · Budget · Scenarios & Levers. |
| 04 | `04_Outreach_Trackers.xlsx` | Pipelines for Schools (25 seeded targets), Tuition Centres (30 area hubs), Societies/RWA (20 seeded), Influencers, and a Referral Leaderboard. |
| 05 | `05_Content_Calendar_Scripts.xlsx` | 26-week content calendar, 12 WhatsApp scripts in Hinglish, 12 ad concepts with hooks, 10 objection handlers. |

## Conventions in the spreadsheets

- **Blue text** = an input you edit. **Black** = a formula, leave it alone.
- **Yellow fill** = a key lever worth revisiting monthly.
- **Yellow-shaded example row** = one fully-worked row showing the expected format.
  Delete it or type over it.
- Every assumption cites its basis in an adjacent column.

## If formula cells look blank in a preview

Expected. The files ship with formulas but no cached results, so GitHub's built-in
xlsx preview and some mobile viewers show those cells empty. **Excel, Google Sheets,
LibreOffice and Numbers all calculate on open** — download the file and the numbers
appear. Every formula was independently evaluated before publishing: zero errors,
and both workbooks agree on ₹1,04,66,165 total revenue and ₹15,77,094 ad spend.

## Important caveats

- Conversion rates are **assumptions**, not measurements. Replace them with your
  own pilot data after Week 5 — the model recalculates automatically.
- School, society and tuition names in file 04 are **targets to pitch**, not
  existing contacts. Contact fields are deliberately blank.
- Festival and exam dates should be **re-confirmed against the CBSE date sheet**
  when it is published; several weeks are anchored to it.
- ₹1 crore is a stretch target. The plan degrades gracefully — see
  *Scenarios & Levers* in file 03, and section 5 of the master plan.
